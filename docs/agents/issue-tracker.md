# Issue Tracker

## GitHub Issues

Issues for this repository are tracked in [GitHub Issues](https://github.com/NASA-JPL-Teamtools-Studio/tts_data_utils/issues).

### How skills use this

Skills like `to-tickets`, `to-spec`, and `triage` will:
- Read issues from GitHub Issues using the `gh` CLI
- Create new issues with `gh issue create`
- Update existing issues as needed

### External PRs

External pull requests are **not** automatically added to the triage queue. If you want to include external PRs in agent workflows, you can enable this in the skill configuration.
